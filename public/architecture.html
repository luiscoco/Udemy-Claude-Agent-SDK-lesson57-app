Each SDK run uses generated fake data. Rules and hooks protect the documentation boundary, an owned loopback collector measures a specific delivery path, and an optional fixed Docker probe verifies OS settings. The SDK controller remains on the host. Explicit probes distinguish model resistance from enforced denial.
